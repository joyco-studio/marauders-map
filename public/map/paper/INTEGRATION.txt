SOFTLY AGED PAPER + MATCHING LIVING BANNER

This revision finds a middle ground between the initial clean golden paper
and the later heavily stained, ripped sheet. Both surfaces now use warm
ivory/light tan, faint cloudy wear and sparse faded age spots. The banner's
sepia hatching is lighter while its thin paper tails remain readable.

FILES
paper_color_rgba.png: main unfolded paper, native 1774 x 887 px, 2:1.
paper_opacity.png: exact extraction of that paper texture's alpha channel.
banner_color_rgba.png: matched blank banner, native 1448 x 1086 px, 4:3.
banner_motion_weights.png: original left/right movement mask, unchanged.
banner_metadata.json: original text box and canvas, with updated asset names.
animate_banner.mjs: the existing noise animation helper, unchanged.

MAIN PAPER
Use the new RGBA texture in place of the strongly aged version. Retain the
existing normal map. Set the color texture to sRGB and material color to white
so the old yellow tint is not multiplied into the new artwork.

The RGBA already includes the revised, mostly intact silhouette. A cutout
material can use alphaTest=0.5, transparent=false and opacity=1.
If the app also has the previous damaged alphaMap assigned, remove it when
using this RGBA's coverage, or replace it with the NEW paper_opacity.png in a
pipeline that applies opacity once. Keeping the old mask keeps the large tears.
The optional separate mask is grayscale numerical data: black=missing paper,
white=paper; use NoColorSpace. Do not multiply the same coverage twice through
both the RGBA alpha and a separate alphaMap.

Keep ink and borders clipped to the same paper silhouette, and retain fixed
unfolded UVs during the folding animation. The new texture has no painted curl
or projected fold shadow; keep the existing curled-corner geometry.

BANNER
The canvas, safe name rectangle and paper-strip anatomy remain aligned with
the original controller. The old movement mask and helper are included for
convenience. Load banner_color_rgba.png as artworkTexture,
banner_motion_weights.png with loadMotionPixels(), and banner_metadata.json
as metadata for createLivingBanner(). Physical width remains a scene-unit
option. The helper's default material already configures sRGB and alphaTest.

VALIDATION
Paper opacity extraction is byte-exact. The banner's alpha silhouette overlaps
the original by 99.372 percent intersection-over-union at the cutout threshold;
its full text rectangle remains covered, and the canvas is unchanged. This
supports retaining the smooth motion mask. The artwork and alpha are preserved
as generated. The revised assets have not been render-tested in the app.
